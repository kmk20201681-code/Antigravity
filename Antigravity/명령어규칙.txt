명령어 규칙

1. 기본 리서치 자료

파일명에 [리서치 결과]가 포함된 파일을
항상 기본 리서치 자료로 사용한다.


2. 추가 자료 입력 명령어

명령어:
리서치 자료 추가 입력

사용자가 위 명령어를 입력하면
이후에 제공하는 파일, URL, 텍스트를
추가 리서치 자료로 인식한다.


3. 기존 자료 보호

추가 자료는 기존 자료를 덮어쓰지 않는다.


4. 출처 구분

기본 자료와 추가 자료의 출처를 구분해서 기록한다.


5. 중복 홈페이지 처리

같은 홈페이지가 중복되면 하나로 묶는다.
단, 발견된 출처는 모두 남긴다.


6. 통합 분석

기본 자료와 추가 자료를 함께 사용해서 분석한다.

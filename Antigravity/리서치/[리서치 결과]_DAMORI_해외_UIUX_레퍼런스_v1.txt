DAMORI UI/UX 벤치마킹 — 해외 사례
작성일: 2026-07-30

목적:
DAMORI의 Diary·Make·Community·Shop·My Page 설계에 참고할 해외 서비스의 핵심 UX를 정리한다.

선정 결과:
1. Mossery — 86점 — 브랜드·Home·Make·Shop·콘텐츠 연결
2. Day One — 82점 — Diary 작성·아카이브·보안
3. Agendio — 77점 — Make 단계·속지 조합·제작물 재사용

================================================================================
1. Mossery
================================================================================

URL: https://www.mossery.co/
역할: DAMORI의 통합 브랜드 경험과 커머스·콘텐츠 연결
구현 난이도: 중간

참고할 점:
- 커버 → 이름 → 속지로 이어지는 짧은 개인화 단계
- 교체형 커버, 리필, 종이 품질 등 구체적인 상품 정보
- Journaling Kit처럼 초보자의 기록 시작을 돕는 구성
- 작가 협업과 사용자 영감을 제품·콘텐츠로 연결하는 방식
- 튜토리얼과 블로그를 Shop에 자연스럽게 연결하는 구조

DAMORI 적용:
- Make를 커버 → 소재·색상 → 속지 → 미리보기로 구성한다.
- 취향별 테마를 컬렉션으로 분리한다.
- 첫 기록 템플릿, 감정 스티커, 사진 카드, 일정 메모를 온보딩에서 제안한다.
- Community의 기록에서 관련 Make 템플릿과 Shop 상품으로 이동하게 한다.
- Home은 판매보다 기록 시작 → 만들기 → 영감 보기의 흐름을 우선한다.

피할 점:
- 복잡한 대형 Shop 메뉴와 반복되는 상품 정보
- 할인·배송 프로모션을 브랜드 메시지보다 강조하는 구성
- 외부 SNS를 내부 Community처럼 사용하는 방식

최종 판단:
Home·Make·Shop·콘텐츠를 잇는 최우선 해외 벤치마크로 활용한다.

================================================================================
2. Day One
================================================================================

URL: https://dayoneapp.com/
역할: Diary 작성과 기록 아카이브
구현 난이도: 추가 기술 검토 필요

참고할 점:
- 로그인 전 핵심 기능 미리보기
- 사진·영상·그림·음성 등 다양한 기록 방식
- Calendar와 On This Day를 이용한 기록 회상
- 템플릿, 리마인더, 태그, 검색 기능
- 데이터 소유권과 보안을 명확히 설명하는 방식

DAMORI 적용:
- 사진, 일정, 감정 스티커, 짧은 메모로 기록 부담을 낮춘다.
- 월간·주간·시간표 보기를 제공한다.
- On This Day는 ‘지난 기록 다시 보기’로 변형한다.
- 연속 기록 경쟁 대신 다시 돌아오도록 돕는 차분한 리마인더를 사용한다.
- Diary에서 ‘내 기록으로 다이어리 만들기’ CTA로 Make를 연결한다.

피할 점:
- 연속 기록 일수를 경쟁처럼 강조하는 방식
- Diary 하나로 전체 브랜드를 설명하는 구조
- 반복적인 앱 다운로드 CTA

최종 판단:
DAMORI 전체가 아닌 Diary와 기록 아카이브에 한정해 활용한다.

================================================================================
3. Agendio
================================================================================

URL: https://agendio.com/customizable-notebooks
역할: Make 단계와 속지 구성
구현 난이도: 높음

참고할 점:
- 템플릿 시작과 직접 구성의 이중 진입
- 주간·월간·일간 및 유선·그리드·도트·무지 속지 선택
- 페이지 순서 변경과 모듈형 구성
- 선택 내용 요약과 결과 미리보기
- 사용자 제작 페이지 저장·재사용

DAMORI 적용:
- ‘추천 구성으로 시작’과 ‘직접 구성하기’를 제공한다.
- 기본 단계를 커버 → 소재·색상 → 속지 → 옵션 → 미리보기 → 저장으로 제한한다.
- 대표 속지를 먼저 보여주고 고급 옵션은 뒤로 배치한다.
- 사용자 속지 아이디어는 Community와 연결한다.
- 자유 배치 편집기는 장기 기능으로 두고 초기에는 템플릿 조합을 우선한다.

피할 점:
- 첫 화면에 모든 옵션을 노출하는 방식
- 서로 호환되지 않는 제작 체계
- 이해하기 어려운 전문 용어와 과도한 자유 편집

최종 판단:
브랜드 비주얼보다 Make의 단계 구조와 제작물 재사용에 집중해 활용한다.

================================================================================
종합 적용 방향
================================================================================

Day One의 가벼운 디지털 기록
→ Agendio의 속지·페이지 제작
→ Mossery의 브랜드·문구·콘텐츠 경험
→ Community와 My Page에서 하나의 계정 여정으로 통합

후속 확인:
- Community 전용 레퍼런스 보완
- 국내 로그인·모바일·커머스 사례 추가
- Make 초기 범위를 템플릿 조합까지로 제한할지 검토
